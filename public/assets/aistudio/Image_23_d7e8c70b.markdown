## Brand & Style

This design system expresses a vibrant, motivating, and delightfully tactile learning experience. It balances high-energy gamification with an uncluttered, distraction-free environment essential for language acquisition. The target audience spans modern learners seeking rapid, rewarding feedback loops without overwhelming visual noise.

The design movement combines **Tactile / Skeuomorphic Micro-Interactions** with **Modern Clean Minimalism**:
- **Tactile Weight:** Buttons, badges, and progress cards carry physical depth through distinct bottom extrusion lips and immediate mechanical depression on interaction.
- **Visual Hygiene:** Surrounding canvases remain crisp, airy, and light (`#FFFFFF` and `#F7F9FA`), allowing primary educational prompts, Rive vector characters, and path nodes to remain the focal point.
- **Instant Affirmation:** High-saturation chromatic accents provide clear, instant visual signals for success, streak commitment, and practice states.

## Colors

The palette establishes an unambiguous functional grammar:
- **Primary Green (`#58CC02`):** Reserved for forward momentum—primary call-to-actions, successful verifications, and master progress bars. Its corresponding shadow base is `#46A302`.
- **Secondary Blue (`#1CB0F6`):** Governs review actions, spaced repetition (FSRS), practice hubs, and secondary informational cues. Paired with `#1899D6` for tactile extrusion.
- **Tertiary Accent Orange (`#FF9600`):** Communicates urgency, daily streaks, heat metrics, and temporal rewards. Paired with `#D97F00` for physical bases.
- **Danger Red (`#FF4B4B`):** Explicitly handles system errors, critical depletion (heart loss), and incorrect answers. Base shadow is `#EA2B2B`.
- **Neutral Hierarchy:** Content and body copy rely on Dark Neutral (`#4B4B4B`) to provide strong contrast without harsh black tones. Subordinate instructions use `#777777`, resting on clean backgrounds (`#FFFFFF` surfaces and `#F7F9FA` canvas) structured by `#E5E5E5` containment borders.

## Typography

Typography prioritizes instant readability during quick interactive challenges and strong legibility across varying viewports.
- **Latin Typeface:** `Inter` is utilized across all weights. Its geometric precision and tall x-height support high legibility in dense multi-choice cards and quick prompt headers.
- **Non-Latin Scripts:** When rendering Kanji, Hanzi, Kana, Arabic, or Cyrillic characters, `Noto Sans` operates as the companion fallback typeface, maintaining visual weight parity with `Inter`.
- **Text Styles:**
  - `headline-xl` and `headline-lg` are reserved for major milestone screens, victory dialogs, and chapter banners.
  - Interactive buttons and gamified badges use all-caps or title-case `label-*` tokens configured with heavy weights (`700` and `800`) and slight tracking expansion (`0.03em` to `0.05em`) to balance the tactile physical container styling.

## Layout & Spacing

The layout model adapts across three distinct responsive stages:

1. **Desktop (> 1024px): 3-Column Persistent Structure**
   - **Left Navigation Sidebar:** Fixed width (`256px`), anchored permanently to the viewport edge. Contains core app destinations and mascot branding.
   - **Main Content Center:** Constrained workspace (`max-width: 600px` to `720px`) housing the vertical node progression path, lesson trees, and active practice modules.
   - **Right Stats Sidebar:** Fixed width (`360px`), housing active quests, heart refill status, league leaderboard ranks, and streak telemetry.
2. **Tablet (600px - 1024px): Consolidated Rail**
   - Left Navigation collapses into an `88px` compact icon rail.
   - Right statistics sidebar transitions to contextual sheets or collapsibles above the main tree.
3. **Mobile (< 600px): Pure Single Column**
   - Navigation transitions to a persistent `64px` bottom navigation bar.
   - Center workspace expands to fill viewport width minus `margin-mobile` (`1rem`).
   - Top chrome carries hearts, gems, and streak counters in a single sticky utility header.
4. **Lesson Session Shell (Headless):**
   - Active learning runs trigger an isolated, distraction-free modal shell. Global navigation rails and sidebars unmount completely, constraining user focus to a single centered card layout with top escape and progress rails.

## Elevation & Depth

Rather than relying on blurred ambient drop shadows, this design system establishes hierarchy through **Tactile Extrusion and Mechanical Push Physics**:

- **Physical 3D Edges:**
  - Interactive cards, buttons, and tokens utilize a solid vertical offset stroke on their bottom edge (created via `box-shadow: 0 4px 0 0 [Shadow-Color]`).
  - Upon active press (`:active`), the element translates downwards (`transform: translateY(4px)`) while the bottom shadow collapses to `0 0 0 0`, simulating a physical mechanical push.
- **Layer Stacking Surfaces:**
  - Base canvas is `#F7F9FA`.
  - Cards and structural modules sit at `#FFFFFF` framed by a 2px solid border (`#E5E5E5`).
  - Active interactive nodes gain subtle elevation with 2px bottom borders (`#E5E5E5` offset by `0 2px 0 0 #D5D5D5`).
- **Focus & Modal Shells:**
  - High-priority confirmation modals and fullscreen lesson sessions deploy a clean scrim overlay (`rgba(0, 0, 0, 0.45)`) that dims background UI without visual blur, preserving system sharpness.

## Shapes

The geometric architecture relies on generous, friendly curves that communicate playfulness without turning generic:
- **Base Rounding (Level 2):** Standard inputs, informational lesson cards, and progress frames adopt `0.75rem` (`12px`) to `1rem` (`16px`) corners (`rounded-lg`).
- **Pill Containers:** Badges, league rank labels, streak indicators, and floating answer token tiles feature fully rounded pill geometries (`rounded-full` or `9999px`).
- **Vertical Learning Nodes:** Circular path milestones employ a circular footprint (`rounded-full`, typically `64px` to `80px` diameter) equipped with an exaggerated bottom lip extrusion.

## Components

### Buttons
- **Primary CTA:** Background `#58CC02`, text `#FFFFFF`, border-radius `1rem`. Bottom extrusion shadow: `0 4px 0 0 #46A302`. Text is uppercase `label-lg`.
  - Hover: Brightness increase (filter: `brightness(1.05)`).
  - Active: `transform: translateY(4px); box-shadow: 0 0 0 0 transparent;`.
- **Secondary (Practice Hub / FSRS):** Background `#1CB0F6`, shadow `0 4px 0 0 #1899D6`, text `#FFFFFF`.
- **Ghost / Neutral Button:** Background `#FFFFFF`, 2px solid border `#E5E5E5`, bottom shadow `0 4px 0 0 #E5E5E5`, text `#4B4B4B`. Active press collapses to flat border.
- **Destructive:** Background `#FF4B4B`, shadow `0 4px 0 0 #EA2B2B`, text `#FFFFFF`.

### Gamified Chips & Badges
- Built using fully rounded pill contours (`border-radius: 9999px`).
- Flame chip (Streak): Surface `#FFF3E0`, text `#FF9600`, icon tinted `#FF9600`, subtle border `#FFE0B2`.
- Heart chip: Surface `#FFEBEE`, text `#FF4B4B`, icon tinted `#FF4B4B`.
- Gems chip: Surface `#E1F5FE`, text `#1CB0F6`, icon tinted `#1CB0F6`.

### Cards & Exercise Answer Tiles
- Surface `#FFFFFF`, 2px border `#E5E5E5`, bottom extrusion `0 3px 0 0 #E5E5E5`, corner radius `1rem`.
- Padding: `space-md` (`1rem`).
- **Selectable State (Multiple Choice Option):**
  - Hover: Border `#1CB0F6`, background `#F0F9FF`.
  - Selected: Background `#DDF4FF`, border `#1CB0F6`, shadow `0 3px 0 0 #1CB0F6`, text `#1899D6`.
  - Correct Assessment: Background `#D7FFB8`, border `#58CC02`, text `#46A302`, shadow `0 3px 0 0 #58CC02`.
  - Incorrect Assessment: Background `#FFDFE0`, border `#FF4B4B`, text `#EA2B2B`, shadow `0 3px 0 0 #FF4B4B`.

### Progress Indicators
- **Lesson Session Bar:** Container height `16px`, background `#E5E5E5`, corner radius `9999px`. Inner bar uses `#58CC02` with an inner top gloss highlight (`rgba(255, 255, 255, 0.35)` 4px strip) to simulate a gel-like liquid fuel bar. Transitions smoothly at 60/120 FPS.

### Input Fields
- Background `#F7F9FA`, border `2px solid #E5E5E5`, radius `1rem`, padding `0.875rem 1rem`. Body typography `body-md`. Focus transitions border to `#1CB0F6` with clean zero-glow definition.

### Path Nodes (Learning Tree)
- Circular buttons `72px x 72px`, fully rounded with a `6px` bottom extrusion base.
- **Active / Unlocked:** Primary `#58CC02` or `#1CB0F6` with animated icon or bouncing mascot head indicator.
- **Mastered (`Emas`):** `#FFC800` face with `#D9A700` bottom rim and star/crown badge.
- **Locked:** Surface `#E5E5E5` with `#CCCCCC` bottom lip, containing a `#AFAFAF` lock glyph.
